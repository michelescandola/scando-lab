# Scando-lab website

This package contains a responsive, single-page website for Scando-lab, led by Michele Scandola at the University of Verona.

## Open the website

Open `index.html` in any modern web browser. The layout, styles and interactions are embedded in the HTML, so no build process is required.
Internet access is only needed when a visitor follows an external profile, network or publication link.

## Publish the website

Upload `index.html` to the root folder of any static hosting service or university web server. It works as-is with GitHub Pages, Netlify, Cloudflare Pages, and conventional Apache or Nginx hosting.

## Edit the content

The document is organised into clearly labelled HTML sections:

- `research`
- `open-science`
- `people`
- `publications`
- `contact`
